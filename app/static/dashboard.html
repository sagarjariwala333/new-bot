Tracker

The bot's own separate record per account + pair. It starts at the tracker starting amount, moves ONLY by each real bot trade's % result, and ignores deposits, withdrawals, manual trades and other pairs - like the equity in your TradingView backtest. Its only job is deciding shadow mode. It never changes a real order, size, stop or balance.

Default Settings

Every field below starts BLANK - nothing is pre-filled. Fill in every field for a platform, press Confirm Default Settings, review the summary, and confirm. Until a platform is confirmed, no new pair can be created on it, and a pair with any blank setting cannot be started. Changing a value here marks that platform unconfirmed again (existing pairs are not touched).

Live trading switch

OFF by default. While OFF, real-money accounts cannot start a pair. Binance testnet / OKX demo accounts are not affected, so exchange connectivity can be checked safely.

Alert / password-reset email

Stored privately on the server only. Used for fallback alerts and password-reset codes (SMTP settings are still set in the environment). Leave blank to send no email.
